# hive-playground
Throwaway repo for testing Hive on kind

## FAQ

**What is this repo for?**
It's a disposable sandbox used to test Hive against a local `kind` (Kubernetes-in-Docker) cluster. Nothing here is production code.

**Can I rely on anything in this repo being stable?**
No. Branches, issues, and files may be created and removed at any time as part of testing.

**How do I run it locally?**
Spin up a `kind` cluster and point Hive at it; there's no special setup beyond that for this repo.

**Where do I report problems?**
Open an issue in this repository.
