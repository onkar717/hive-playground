# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it
privately rather than opening a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/onkar717/hive-playground/security/advisories/new)
feature to submit a report. This creates a private advisory visible only to
the repository maintainers.

Please include as much detail as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, screenshots, or proof-of-concept code

We will acknowledge your report and work with you on a fix and disclosure
timeline.
